## 运行参数

主检测置信度为0.25，NMS IoU为0.45。检测框中心确定源网格，7次观察中至少5次分类组一致后形成稳定目标，当前观察也需匹配。

正方体放右区，长方体和桥型放左区。夹爪OPEN=100，正方体CLOSE=69，其他物体CLOSE=40，速度为20。红橙二级分类使用0.80置信度和0.30领先差值阈值。

## 实验记录

实机按教师认可的方式从五个物体开始，补放一次黄色方块，共完成六轮搬运。六轮任务和另一轮五次v4测试各有独立日志。

桥型仿真的最终结果位于 `03_Simulation/experiment3_sim_bridge_20260921/results/bridge_20260921_222016/`，六个物体均放置正确，其中桥型两个。

红橙分类器的84/84测试图结果和36/36视频回归结果位于07_Training。它们是图像测试成绩，未计入机械臂搬运次数。
