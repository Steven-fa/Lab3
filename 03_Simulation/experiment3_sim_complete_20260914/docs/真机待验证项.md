# 历史阶段计划：真机验证（2026-09-14）

本文保留原场景仿真阶段的真机验证计划，不表示当前提交包仍未完成实机验收。实机已按教师认可的五物体加一次补料方式完成六轮搬运，相关视频及日志见 [实机材料](../../../04_Evidence/)，逐次结果见 [记录索引](../../../05_Records/)。

以下为当时拟定的现场验证项目，作为阶段记录保留：

| 原计划项目 | 验证内容 |
|---|---|
| 真实相机与网格 | 固定相机、确认图像话题；按实际机位标定 4—6 个网格的像素范围 |
| 真机动作适配 | 每个网格的安全位、取物位和分类区放置位；使用已有实测示教轨迹与真机驱动接入任务接口 |
| 检测模型验证 | 使用前序训练模型，在当前光照、相机高度和实物上验证类别及框，不直接套用仿真 HSV 阈值 |
| 两类六物体任务 | 至少两类、共六个实物，至少正确分类五个；过程中无人指定类别或触发每个动作 |
| 异常处理 | 实测空网格、未知物体；验证失败时安全返回或停止 |
| 验收材料 | 真机演示视频、逐物体记录、异常记录与实机结论 |

本历史仿真目录沿用mechArm 270 M5模型及标定夹爪几何，不启用真机执行后端。实机Pi机械臂的关节零点、坐标、TCP、Z高度及夹爪量以现场标定为准；当前实机工程位于提交根目录的02_Physical。

本包中的 `simulation_demo.mp4` 仅为仿真录像。`real_vision_reference/README.md` 和模型文件来自原有视觉包，不构成本次实机整理任务的验收证据。
